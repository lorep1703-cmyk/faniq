## ICP primario — Club sportivo italiano di medio livello

### Caratteristiche del club
| Attributo | Valore target |
|-----------|--------------|
| Sport | Calcio (focus iniziale) |
| Categoria | Serie C / Lega Pro / Serie B |
| Tifosi abbonati | 500 – 5.000 |
| Struttura interna | Ha un responsabile marketing o commerciale (anche part-time) |
| Dati disponibili | Abbonamenti, biglietti, acquisti shop in formato digitale |
| Relazione con i dati | Li raccoglie ma non li analizza sistematicamente |

### Caratteristiche del decision maker
| Attributo | Valore target |
|-----------|--------------|
| Ruolo | Responsabile marketing / Direttore commerciale / General manager |
| Problema principale | "Non so chi sono i miei tifosi più fedeli" / "Non so come recuperare chi ha smesso di venire" |
| KPI che segue | Abbonamenti venduti, presenze allo stadio, revenue stadio |
| Familiarità tech | Media — usa Excel, forse un CRM base |
| Processo decisionale | Relativamente rapido per budget <500€/mese |

### Trigger di acquisto
- Stagione nuova in arrivo → deve vendere abbonamenti
- Calo di presenze → cerca soluzioni
- Nuovo responsabile marketing → vuole fare bene
- Ha appena preso una nuova categoria → più risorse disponibili

### Anti-ICP (chi NON è il cliente giusto ora)
- Club di Serie A (troppo strutturati, hanno già soluzioni)
- Club dilettantistici puri (budget quasi zero, dati non strutturati)
- Club di sport di nicchia senza dati digitali sui tifosi
- Club con CRM enterprise già in uso
