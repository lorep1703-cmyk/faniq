# Assumptions — Ipotesi non ancora confermate

Questo file raccoglie le ipotesi che guidano le decisioni di FanIQ ma che non sono ancora state validate da dati reali, clienti o feedback di mercato.

**Regola:** Quando un'ipotesi viene confermata o smentita, spostarla in `decisions/decisions_log.md` con la data e la fonte di validazione.

## Come aggiornare questo file

Quando validi o smentisci un'ipotesi:
1. Aggiungi una riga sotto l'ipotesi con `> ✅ Confermata` o `> ❌ Smentita` + fonte + data
2. Sposta la voce in `decisions/decisions_log.md`
3. Aggiorna la strategia se necessario (questioni aperte in `CONTEXT_HANDOFF.md`)
