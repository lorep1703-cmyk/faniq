## Come usare questo workspace

1. **Leggere `instructions.md`** prima di qualsiasi sessione di lavoro importante
2. **Leggere `PROJECT_STRUCTURE.md`** per capire dove trovare e dove mettere ogni cosa
3. **Aggiornare `decisions/decisions_log.md`** ogni volta che si prende una decisione
4. **Aggiornare `decisions/open_questions.md`** ogni volta che emerge un dubbio
5. **Usare `prompts/prompt_library.md`** per trovare prompt pronti da mandare a Claude Code
