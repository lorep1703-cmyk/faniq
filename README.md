# FanIQ

SaaS B2B di fan intelligence per club di calcio italiani (Serie C / Lega Pro): i club caricano i CSV di abbonamenti, biglietti e shop, e FanIQ dice chi recuperare, chi premiare e quando agire.

- **Prodotto live:** https://faniq-seven.vercel.app
- **Regole, stack, comandi:** [`CLAUDE.md`](CLAUDE.md) (letto anche da Codex tramite `AGENTS.md`)
- **Stato attuale e questioni aperte:** [`CONTEXT_HANDOFF.md`](CONTEXT_HANDOFF.md)
- **Idee di prodotto:** [`product/feature_ideas.md`](product/feature_ideas.md)
- **Go-to-market:** `gtm/`, `marketing/`, `sales_assets/`, `research/`, `decisions/`

Avvio locale: `./start.sh` (backend :8000, frontend :3000). Mai dati reali di tifosi nel repo.
